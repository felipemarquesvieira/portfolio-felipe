Um pouco sobre mim

Conheça minha trajetória

Sou estudante de Análise e Desenvolvimento de Sistemas e estudo três frentes: programação, banco de dados e desenvolvimento web.

Em Linguagem C, pratico vetores, funções, estruturas de repetição e sistemas de gerenciamento. Em Python e SQL, faço atividades de programação, banco de dados e manipulação de informações.

O FM SPORTS reúne essas frentes em um sistema só: Python e Flask no servidor, SQLite para os dados e uma interface web com painel de indicadores, tabela de produtos e cadastro de novos itens. Ele está publicado e pode ser testado online.
